# 品質チェックレポート

このファイルは、品質チェックレポート作成用のテンプレートです。

実際の品質チェック結果は、このファイルへ保存しないでください。

`15-quality-check.md` を実行した後、Codexはこのテンプレート形式で品質チェックレポートを作成し、以下のフォルダへ保存してください。

```md
docs/quality-reports/
```

ファイル名は以下の形式にしてください。

```md
YYYY-MM-DD-XX-タイトル.md
```

`XX` はその日の実施回数です。

品質チェック項目そのものは、以下のチェックリストを参照してください。

- `13-static-checklist.md`
- `12-wordpress-checklist.md`
- `14-production-checklist.md`

このファイルには、チェック項目を重複して記載しないでください。
