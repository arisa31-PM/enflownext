# 本番公開前・納品前チェック

## 役割

このファイルは、本番公開前・納品前にAIが必ず実施する最終チェックルールである。

静的サイトの場合は、以下の順で確認する。

1. `13-static-checklist.md`
2. `14-production-checklist.md`

WordPressサイトの場合は、以下の順で確認する。

1. `13-static-checklist.md`
2. `12-wordpress-checklist.md`
3. `14-production-checklist.md`

公開・納品に関わる最終確認であるため、問題があれば修正してから完了報告を行うこと。

---

# デプロイ前

確認すること

・最新バックアップを取得したこと
・Gitの変更が適切にcommit / pushされていること
・npm run buildを実行したこと
・styles.min.cssが生成されていること
・script.min.jsが生成されていること
・圧縮ファイルが最新であること
・本番不要ファイルをアップロード対象から除外したこと

---

# 本番WordPress

確認すること

・WP_DEBUGがfalseであること
・テスト環境では「検索エンジンがインデックスしない」にチェックが入っていること
・本公開時には「検索エンジンがインデックスしない」のチェックを外したこと
・noindex / nofollowを本公開前に解除したこと
・パーマリンクを確認したこと
・タイムゾーンを確認したこと
・SiteGuardを確認したこと
・不要プラグインを削除したこと
・未使用テーマを削除したこと
・不要投稿 / 下書きを削除したこと

---

# 本番表示

確認すること

・全ページ表示確認を行ったこと
・リンク切れがないこと
・404確認を行ったこと
・画像切れがないこと
・CSS崩れがないこと
・JavaScript動作確認を行ったこと
・Console Errorがないこと
・PHP Error / Warning / Notice / Fatal Errorがないこと

---

# Network確認

確認すること

・styles.min.cssが200であること
・script.min.jsが200であること
・主要画像が200であること
・404 / 403になっているリソースがないこと

---

# キャッシュ

確認すること

・CSS / JS変更後に最新ファイルが配信されていること
・filemtime等のバージョンが更新されていること
・必要に応じてサーバー / WordPress / ブラウザキャッシュを削除したこと

---

# フォーム本番確認

確認すること

・管理者宛メールが届くこと
・自動返信メールが届くこと
・迷惑メールフォルダも確認したこと
・文字化けがないこと
・Thanksページまたは完了処理が正常であること
・二重送信等の問題がないこと

---

# ブラウザ・実機

確認すること

・Chromeで確認したこと
・Edgeで確認したこと
・Safariで確認したこと
・iPhoneで確認したこと
・Androidで確認したこと

---

# SEO

確認すること

・titleを確認したこと
・descriptionを確認したこと
・canonicalを確認したこと
・OGPを確認したこと
・faviconを確認したこと
・Apple Touch Iconを確認したこと
・robots設定を確認したこと
・noindex解除を確認したこと
・サイトマップを確認したこと

---

# 納品・公開

確認すること

・本番公開直前のバックアップを取得したこと
・本番URLで最終確認したこと
・不要な開発ファイルがサーバーに存在しないこと
・不要な.DS_Storeが存在しないこと
・検索エンジンのインデックス設定を最終確認したこと

---

# 最終判定

最後に以下を確認すること

・静的サイトの場合は `13-static-checklist.md` と `14-production-checklist.md` の全項目を確認済みであること
・WordPressサイトの場合は `13-static-checklist.md`、`12-wordpress-checklist.md`、`14-production-checklist.md` の全項目を確認済みであること
・未確認項目がある場合は、理由と確認予定を報告すること
・問題がある場合は修正してから完了報告すること

問題がなければ

「納品・提出可能」

と判断すること。
