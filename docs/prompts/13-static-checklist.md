# 静的サイト・フロントエンド品質チェック

## 役割

このファイルは、静的サイト・WordPress共通で実装後にAIが必ず実施するフロントエンド品質チェックルールである。

静的サイトの場合は、以下の順で確認する。

1. `13-static-checklist.md`
2. `14-production-checklist.md`

WordPressサイトの場合は、以下の順で確認する。

1. `13-static-checklist.md`
2. `12-wordpress-checklist.md`
3. `14-production-checklist.md`

実装完了後は必ずこのチェックを行い、問題があれば修正してから次のチェックへ進むこと。

---

# レスポンシブ・レイアウト

確認すること

・意図しない横スクロールが発生しないこと
・320px画面幅での表示確認（最小幅）
・375px画面幅での表示確認（ピクセルパーフェクト）
・767px画面幅での表示確認（ブレークポイント-1px）
・768px画面幅での表示確認（ブレークポイント）
・1440px画面幅での表示確認（ピクセルパーフェクト）
・1920px画面幅での表示確認（大画面）
・2650px画面幅での表示確認（最大幅）
・文字サイズの最小値が担保されていること（10px未満にならない）
・画像を変更したり、テキストやコンテンツが増えても表示崩れしないこと
・height固定でレイアウトを作っていないこと
・ブレークポイントは768pxの1箇所のみであること

---

# デザイン再現

確認すること

・フォントが適切であること
  - color
  - size
  - weight
  - family
・box-shadowの抜けがないこと
・border-radiusの抜けがないこと
・誤字脱字がないこと
・余計なスペースがないこと
・画像やデザインカンプとの相違がないこと
・余白がデザインカンプ通りであること
・英字・日本語フォントを正しく使い分けていること

---

# リンク・操作

確認すること

・TEL設定時、PCでは不要なtel挙動になっていないこと
・スマホでは電話番号をtelリンクにしていること
・クリック範囲が適切であること
・ヘッダーロゴやnavリンクのクリック領域が十分確保されていること
・ホバー時の動きが指示通りであること
・ホバー指示がない場合でも自然なtransitionがあること
・クリック可能要素でカーソル表示が適切であること
・正しいリンク先になっていること
・リンク切れがないこと
・MOREボタンを確認すること
・TOPへ戻るを確認すること
・プライバシーポリシーを確認すること
・404になるリンクを残していないこと

---

# ブラウザ・実機

確認すること

・Chromeで表示確認すること
・Edgeで表示確認すること
・Safariで表示確認すること
・iOS（iPhone）実機確認を行うこと
・Android実機確認を行うこと
・各環境で拡張機能由来を除くConsole Errorがないこと

---

# HTML

確認すること

・HTML構造が適切であること
・HTML5のセマンティックタグを使用していること
・見出し構造が適切であること
・h1が1ページに1つであること
・下層ページでロゴをh1にしていないこと
・article / section / nav / aside / footer / header を適切に使い分けていること
・buttonとaタグを適切に使い分けていること
・リストはul / olを使用していること
・Q&Aはdl / dt / ddを使用していること
・日付はtimeタグを使用していること
・開始タグ・閉じタグなどの設定不備がないこと
・不要なページ・パーツ確認専用ページが残っていないこと
・不要なコメントが残っていないこと
・生成済みHTMLのインデントが整っていること

---

# CSS / SCSS

確認すること

・FLOCSS構成になっていること
・BEM命名規則を守っていること
・remを基本単位としていること
・heightで高さを作っていないこと
・paddingで高さを作っていること
・!importantを使用していないこと
・overflow:hiddenを安易に使用していないこと
・transformを必要最小限にしていること
・calc / clamp / vwを原則使用していないこと
・ネストが深くなりすぎていないこと
・不要なSCSSが残っていないこと
・不要なCSSが残っていないこと

---

# 画像

確認すること

・imgのaltが適切であること
・FVなど初期表示画像にloading="lazy"を設定していないこと
・FV画像にはloading="eager"を設定していること
・FV画像にはfetchpriority="high"を設定していること
・imgにwidth / heightが設定されていること
・必要な画像にdecoding="async"が設定されていること
・FV以外に適切にloading="lazy"が設定されていること
・WebP / JPG / PNG / SVGなど適切な形式を使用していること
・装飾テキストを画像化する場合、必要に応じてパス化SVGになっていること
・必要なラスター画像が適切な解像度で書き出されていること
・ダミー画像や不要画像が残っていないこと
・画像未設定でも大きく崩れないこと

---

# SEO・head

確認すること

・noindex / nofollow設定を確認すること
・OGPタグの設定を確認すること
・faviconの設定を確認すること
・Apple Touch Iconの設定を確認すること
・title / descriptionを確認すること
・不要なmetaや重複設定がないこと
・h1が適切であること
・altが適切であること

---

# パフォーマンス

確認すること

・初期表示に不要なscriptが適切に遅延されていること
・FV画像のLCP対策が行われていること
・CLSが発生していないこと
・CSS / JS変更時にキャッシュ更新が行われる構成であること
・imgにはwidth / heightを設定していること
・レイアウトシフトを発生させないこと

---

# JavaScript

確認すること

・不要なJavaScriptが残っていないこと
・必要最小限のJavaScriptで実装していること
・Console Errorが出ていないこと
・主要な操作が正常に動作すること
